# Lucide icons

`lucide.svg` is a selected SVG symbol sprite from `lucide-static` 1.61.0.
Source: https://registry.npmjs.org/lucide-static/-/lucide-static-1.61.0.tgz

The original ISC license and copyright notices are in `lucide-LICENSE.txt`.
Symbols retain Lucide's 24 × 24 view box and inherit the interface's stroke colour.
A few legacy names are aliases for canonical v1 icons. All icons are served locally;
no icon CDN, runtime dependency, or build step is required.
